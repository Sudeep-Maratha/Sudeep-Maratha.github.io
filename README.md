# Sudeep H M — Creative Developer Portfolio

Responsive creative portfolio with a night-sky/mountain hero scene, gradient typography, project cards, and mobile navigation. Built with plain HTML, CSS, and JavaScript.

## Run locally
Open `index.html` in a browser. No build tools are required.

## Personalize
- Replace `YOUR_EMAIL@example.com` with your email.
- Replace generic GitHub and LinkedIn links with your profile URLs.
- Update project descriptions/statuses and add links to real repositories.
- Keep skill and project claims accurate to your experience.

## Publish with GitHub Pages
1. Create a public repository named `YOUR-USERNAME.github.io`.
2. Upload `index.html`, `style.css`, `script.js`, and `README.md` to its root.
3. Go to **Settings → Pages**.
4. Choose **Deploy from a branch**, select `main` and `/(root)`, then save.
5. After deployment, visit `https://YOUR-USERNAME.github.io`.
